# Backend — reserved for Phase 2

No backend runs in Phase 1. This directory is the boundary for the future Python / FastAPI / Pydantic / Uvicorn application. Never place privileged API keys in frontend files.

Planned modules under `app/`: authentication, patients, consultations, voice (Gnani.ai STT/TTS), AI (Gemini), evidence, translation, safety, notifications, doctor reviews, records, analytics, and audit logging. Implement these only in their approved phases. No provider endpoints or authentication contracts are assumed here.
